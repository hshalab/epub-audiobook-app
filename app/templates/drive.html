Add new OAuth client
Hướng dẫn: tạo OAuth client mới trên Google Cloud
  1. Truy cập Google Cloud Console > Credentials.
  2. Chọn hoặc tạo một project (dùng project riêng nếu muốn quota API riêng).
  3. Bấm + Create Credentials > OAuth client ID.
  4. Application type: Web application.
  5. Authorized redirect URIs: thêm {{ request.base_url }}drive/callback.
  6. Bấm Create. Copy Client ID và Client Secret vào form bên trên.
  7. Vào Library, tìm "Google Drive API" → bấm Enable.

Kaggle

Để notebook batch chạy trên Kaggle truy cập Drive trực tiếp (tự tải package về và upload .wav lên Drive khi chạy - resume được qua nhiều session): bấm "Copy Kaggle credentials" ở dòng tài khoản tương ứng, rồi trên Kaggle vào Add-ons > Secrets, tạo secret tên GDRIVE_CREDS với giá trị vừa copy và bật cho notebook. Mỗi tài khoản có credentials riêng - phải dùng đúng tài khoản đang chứa export cần chạy. Secret này chứa refresh token của tài khoản Drive - chỉ dán vào Kaggle Secrets (riêng tư), không dán vào code của notebook.
